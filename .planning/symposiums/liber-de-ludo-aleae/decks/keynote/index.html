Glossary

circuit / circuitus
The full set of equally possible outcomes (sample space). Not a stop-loss “circuit-breaker.”
Liber de Ludo Aleae
Cardano’s Book on Games of Chance, written ~1564, printed 1663.
aequitas
Equal conditions: same information, tools, stakes, and light. Fairness as a contract, not a 0–1 mood.
odds r : s
Favorable ways to unfavorable ways. Fair price matches this ratio.
EV
Expected value: probability-weighted average payoff. Fair game ⇒ EV = 0.
house edge
Expected loss per unit stake (−EV / stake) when the payout is worse than fair. At 4:1 on a fair six this is 16.7%, not the 20% payout-shortfall.
ROTM
Reasoning On The Mean — the error of treating n × p as a probability (3×1/6 is not ½).
n
How many independent casts (trials) you have actually observed.
scientia / fortuna
Knowledge vs luck. A method vs a single favorable throw.
sidecar
Extra fields published next to an existing score. Does not rewrite the locked core struct.
genesis
WeftOS’s locked founding governance rules. Changing EffectVector’s five faces is a breaking change.
EffectVector
Five impact numbers on a privileged action: risk, fairness, privacy, novelty, security.
MetaHarness (MH)
Optional harness-readiness scorer (fit, compile, coverage, safety, memory). Not required to run weft.
promote
Make a candidate the official champion. Forbidden without receipts and confirm.
LDA-ADR
Local symposium decision record. Not a WeftOS central ADR until someone graduates it.
Nova / Vetus / Coniunctio
New-doctrine room / existing-scores room / the combining table.
rhyme / cousin / false friend
Same question / same family different primitive / same English word, different job.
Prince
Cardano’s leftover name for luck as a person. Detector stays; the ghost goes.
WEFT-322
Cost / token stop-loss ticket. Not a sample space.
ADR-090 / ADR-096
090: world-model must not override ECC. 096: MetaHarness is optional; no silent promote.
