# Knowledge as Portfolio

Cardano's book is a **portfolio manual**: many small, equal-condition wagers; never the house; never the whole purse; count remaining work when the match stops.

## Job (Team Tabula)

Write the portfolio / delegation section of `panels/P2-tabula.md`:

1. **Knowledge as a book of wagers**: each memory, skill, model, and citation has an implied *p*, a stake (attention), and a ruin (wrong high-stakes act). AgentDB `patterns` should store *n* and calibration, not only the recipe.
2. **Diversification**: one model, one judge, one retrieval index = one die. Uncorrelated circuits (different hosts, different evals, different sensors) are the hedge.
3. **Delegation**: the problem of points. Pay / credit / continue by **remaining work × P(finish)**, not sunk tokens. Interrupted swarms should split by continuation value.
4. **Pricing and arbitrage index**: if two circuits price the same event differently (router A vs B, judge A vs B), the spread is either edge or misspecification. Index it; do not silently take it.
5. **Economic decisions generally**: hire, buy GPU, promote a ViewSpec, open a Plane item — all wagers. Same contract: circuit, odds, stake, edge, ruin.

One ASCII diagram: knowledge book as a row of dice with different circuits.

Do not invent dollar savings. No fake $ numbers (MetaHarness savings skill rule).
