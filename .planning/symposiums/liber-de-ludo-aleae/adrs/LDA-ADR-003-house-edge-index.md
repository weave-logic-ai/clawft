# LDA-ADR-003 — House-edge / advantage index

**Status**: Draft  
**Parents**: ch. 14 fair wager; fraud catalog; routing / vendor / judge

`edge = −EV / stake` when EV is negative (expected loss per unit staked). On a fair six paying 4:1 instead of 5:1 this is **16.7%**, not the 20% payout-shortfall `1 − offered/fair`. Undeclared positive edge is a house table. Index it on opportunities, model routing, and evals that keep only winners.
